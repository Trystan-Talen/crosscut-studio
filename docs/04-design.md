# 重构设计

方向：Crosscut 跨境创作台。深墨绿导航、纸白画布、青柠行动色，减少原站黑底小字与层叠弹窗。系统中文字体，无外部字体加载依赖。

## 信息架构
制作：工作台 / 创作工作室 / 创意Agent / 工作流。
研究：灵感雷达 / 视频拆解 / 爆款复刻。
管理：素材库 / 项目 / 任务记录 / 设置。
工具箱与视频2.0合入创作工作室，但保留专用深链接、字段与模式。各入口对应同一份草稿和任务数据。

## 核心交互
- 工作台常用工具直接进入专用表单；左侧素材与输入，右侧预览/结果，高级参数折叠。
- 步骤式创作在顶部固定显示素材→创作→生成→成品。保存草稿与开始生成分开。
- 所有素材选择器支持库内选择及上传，显示格式/体积/时长，错误在字段旁。
- 任务提交后立即进入记录面板，状态、真实进度、输出、取消/重试按钮随状态改变。
- 参考广告详情提供收藏、拆解、复刻；保留返回时的筛选。
- 拆解采用视频+阶段时间轴，右侧分镜/机制/提示词标签；结果版本单独可切换。
- 依赖未配置时显示配置入口，仍允许编辑和保存草稿，不显示假预计完成。
- 模态框单层、Escape关闭、焦点返回；删除进入回收站，操作反馈可恢复。

## 视觉参数
画布#F5F6F1，卡片#FFFFFF，主文字#152C27，次级#62706A，边线#DCE2D8；侧栏#142D27，行动色#D8F58B；错误#B42318。
桌面侧栏224px，主区最大1600px；24px栅格；卡片16–22px圆角；正文14px/1.6；页面标题30–36px；主操作44px高。
1120px以下减少并排面板；840px以下侧栏成为可开合抽屉，表单双栏变单栏；表格可横向滚动且主要状态保留。
焦点2px绿色外框，控件明确label；动效尊重prefers-reduced-motion；状态同时用文字和颜色表达。

## 原型门槛
静态原型只验证导航、表单结构、草稿/任务反馈；显式标注设计原型，不冒充后台任务。
正式应用继承上述组件，但以真实API替代原型状态。
