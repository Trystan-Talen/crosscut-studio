## 本轮前端只读复评

重点检查API错误与会话处理、任务/草稿复用、素材上传部分成功、分析版本、批次状态、Agent本地存储、原生dialog和字幕预览。发现的Agent草稿隔离问题已修复，其余结果如下：

- 正常页面不使用`dangerouslySetInnerHTML`或`eval`显示外部文本；React文本渲染和技术详情折叠没有把上游内容当指令。
- 长任务进度来自真实API状态/事件，轮询用于读取状态，不用定时器制造生成进度；未配置服务没有假成功分支。
- 素材Picker会在重新打开时从当前已选素材同步；共享后端再次检查数量、类型和归属，不将客户端筛选当权限控制。
- `Drawer`使用原生`dialog.showModal()`、可访问标题、关闭按钮和Escape；窄屏有宽高限制及可滚动内容。控件有统一`focus-visible`。这些是代码检查结果，实际焦点约束/返回、键盘遍历与窄屏溢出仍由浏览器证明。
- Provider秘密不在浏览器缓存中持久化；前端仅编辑输入后发送服务器，API不回显密钥。Agent草稿是用户创意内容，现已按用户隔离，不与服务密钥混用。
- 草稿恢复、部分上传反馈、跨页批次状态与取消错误等新增路径必须在主审统一构建后验收，不使用先前版本截图覆盖新代码。

## 遗留服务依赖与产品差异

1. **真实AI凭据缺失**：OpenAI兼容、Ark、ElevenLabs、HeyGen虽然有官方协议适配与fixture，仍需用户独立账户、密钥、正确模型/人物/声音ID、权限和额度；未验收真实生成质量、时延、成本及账户可用性。
2. **专用工作流只实现外接协议**：`workflow-http-v1`客户端不能自行生成手持商品、爆款复刻、链接广告成片或无痕字幕修复。项目未交付这些上游服务，须明确为外部依赖；不可拿通用fixture视频抵充。
3. **供应商限制**：部分视频参考输入、IVC核验、特定人物动作和Enterprise替换音色不在当前适配范围。远端取消必须以供应商确认语义为准；删除结果不是停止生成/计费。
4. **原站专有数据与隐藏逻辑**：不复制广告库、人物/音色素材、商业积分/支付、内部算法。雷达采用用户导入数据和多选，自有行业值不是伪造的原站分类树；缺失指标显示未知。
5. **重构与未观察项分开**：原创UI、33静态字幕美术、本地账号ID、固定主题、项目/备份等是DEC；原站隐藏权限、付费效果、未触发异常是BLOCK-SRC。原站未观察到的能力不能被反向列成其必缺功能。
6. **仍需业务对照的部分**：语义拆解与Agent最新实现边界见05矩阵；Agent现已补充用户明确提交的视频/产品复刻模式，不能据此称为自动规划或真实多服务生成已验证。具体字段、输入限制、模板和交互差异逐项记载，不用入口数量作为完成率。

## 主审补充：最后后端与媒体复评

- **P1 收费提交与取消竞争**：取消在worker领取后、提交占位前到达可能被忽略。提交占位与取消均增加当前状态和`cancel_requested`条件；用受控竞态先复现失败，再验证只有先获胜的操作生效。
- **P1 已收费响应后重试**：同步AI已经返回2xx，但输出解析、下载、解码、后处理或数据库提交失败，不能当普通失败重新生成。适配器记录已受理状态并转换`RESULT_PROCESSING_FAILED`；worker完成保存失败转换`RESULT_COMMIT_FAILED`，均进入待核对并禁止自动重发。明确的首次400/401/429拒绝保留正常重试路径。
- **P1 生成覆盖人工编辑**：分析提示词生成期间用户已编辑保存的内容可能被迟到结果覆盖。记录生成基线，完成时条件更新，仅未变化的字段接收模型结果。完成和重试事务改为立即事务。
- **P1 容器信任**：ffprobe的`matroska,webm`组合名不能判定WebM。读取有界EBML头和DocType，核验WebM codec集合；MKV、WebM、音频WebM真实文件及伪造容器用例通过。
- **P2 手机布局/键盘复验**：正式构建390px下首页与10个主页面均无横向溢出；关闭抽屉不再出现在AX中，打开焦点进入抽屉，Escape返回开启按钮。结果与参考详情原生弹窗也完成焦点恢复实测。
- **P2 空提示词**：分析页把已保存的空字符串作为合法编辑结果，不再用旧模型文本填回清空内容。

上述后端修正专项13项通过、类型检查通过；最终完整回归数字和范围在[本地验收报告](../07-acceptance.md)归档。外部真实AI及专用服务缺口不因此消失。
