# ADR-001：本地模块化单体与媒体Worker

状态：选定，已完成可实现性与规格独立复评；执行验证见后续验收记录。

- Node.js22.22+，TypeScript strict，npm锁文件。
- React19+Vite8构建客户端，Lucide图标，CSS变量构建设计系统。
- Fastify5长期API进程；Zod共享输入契约；better-sqlite3实际驱动版本核验。
- 独立Node worker进程；FFmpeg/ffprobe8；API只提交，不在HTTP生命周期执行长任务。
- Worker职责为任务领取、租约续期、执行、取消、输出验证与事件落盘。媒体渲染与外部provider适配分别成模块；父批次聚合子任务，不让单个大循环阻断取消与恢复。
- 单仓库 src/web、src/server、src/shared、tests、scripts。规模足以模块化，无需预先制造多包发布成本。
- 本机HTTP仅绑定127.0.0.1；同源cookie会话+Origin验证；密码scrypt；登录限速。
- 数据库在 data/app.sqlite，媒体data/media，日志data/logs；运行数据/密钥忽略Git。
- provider配置元数据进SQLite，密钥AES-256-GCM加密，本地随机主密钥0600；响应只返回是否配置，不回传密钥。
- 能力注册表与工具目录分离：同一工具可以需要多个能力；模型显示名、API ID、支持参数和验证等级独立存储。适配器必须对请求、错误、异步轮询、幂等和产物下载定义明确协议。普通OpenAI兼容文本端点不能视作数字人/视频端点。
- HTTP外部访问集中在安全客户端；超时/字节限制/重定向检查；不运行远程脚本。
- 安全客户端同时覆盖产品抓取、参考媒体和provider产物下载；DNS解析结果及每次重定向都执行内网/回环/链路本地地址检查，并防止检查后DNS变化。可配置供应商端点与用户提交URL分开授权；任何本地网关支持必须为明确受控配置，不能借用户URL放宽SSRF保护。
- 子进程使用参数数组调用，不拼接shell；输出到任务隔离临时目录；拒绝路径逃逸、符号链接逃逸与媒体URL直接交给FFmpeg。限制并发、每任务时间、输入总字节和输出总字节，取消终止进程组并清理未发布临时文件。
- FFmpeg构建须在启动诊断核验所需编码器/滤镜和中文字体；不能仅凭版本存在认定字幕渲染可用。macOS依赖路径可配置，首次缺失需给出确切修复步骤；不静默从不明来源下载可执行文件。
- 测试采用Vitest+Fastify inject，使用独立临时数据库与生成媒体；浏览器QA使用现有工具，不引入第二套浏览器自动控制。
- Mac .command包装shell脚本；路径含空格/中文必须可用；不全局安装、不修改系统设置。
- 启动锁/PID需校验进程归属，重复启动复用现有实例；停止脚本只终止本项目API/worker及其子进程。启动失败保留终端诊断与日志位置。
- 备份通过SQLite一致性备份机制（或受控停止服务）取得数据库，连同已发布媒体、版本信息和恢复清单校验；不能在WAL写入中只复制主数据库文件。密钥备份采用明确的独立导出流程；缺主密钥的恢复仍可读取业务数据，但所有provider必须重新配置。测试在隔离目录恢复，不能覆盖活跃数据验证。

禁止事项：用原站私有API/会话服务新应用，硬编码账号密码，模拟AI成功，下载原站专有角色库，捏造雷达数据量。

权衡：SQLite单写适合本地/小团队起步；水平多节点需要未来迁移数据库与对象存储，不承诺当前实现无限并发。
