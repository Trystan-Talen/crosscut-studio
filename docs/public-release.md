# 公开发布说明

发布日期：2026-10-15。

公开仓库包含应用源码、依赖锁定文件、测试、启停与备份脚本、文字调查记录、本地演示截图及原创示例成片。

原站调查截图可能包含账号名或私有创作记录，因此 `docs/evidence/OBS-*.jpg` 仅在本地保留，不进入公开提交。文字记录中的同名截图引用表示原调查的本地证据，公开仓库不提供这些图片。公开版本使用独立的初始提交，原本地提交历史不随仓库发布。

`data`（数据）、`backups`（备份）、依赖安装目录、构建产物、环境配置、日志和进程文件均被版本管理忽略。不要将真实服务商密钥或个人业务文件加入源码或测试。

历史验收记录中的原电脑绝对路径已替换为 `<local-project>`（本地项目）和 `<local-delivery>`（本地交付目录）占位符；文字调查中的原站任务编号已省略，其余验收结果保留。它们记录原交付环境的结果，不代表所有电脑都已通过同样验收。启动说明已改为仓库自身的相对路径。

本次发布前，类型检查、格式检查及新增入口脚本的语法检查通过。当前工作目录缺少 Rolldown（打包工具）的原生依赖，自动测试在启动时中止，后续生产构建未执行；历史 156 项测试通过记录不代表本次重新运行通过。新电脑应先按锁定文件完整安装依赖，并准备媒体处理工具，再执行完整检查。

真实付费模型推理及尚未实现的专用生成引擎仍受原功能矩阵与验收报告所述限制，公开发布不改变这些能力边界。
