# 功能规格与验收合同

状态：开发合同；原站事实见 OBS 系列，以下独立产品规则均为 DEC。
产品暂名：Crosscut 跨境创作台。交付为本地 Mac 应用，SQLite 与媒体文件位于本项目 data 目录，不向云托管迁移用户数据。

“本地应用”指数据默认存储位置，不代表全部 AI 在本机推理。用户选择并配置外部服务商后，执行前须明确展示将发送的文字/媒体类型及服务商；随后只发送该次任务必需的素材。本地后期能力与外部 AI 能力在目录、提交按钮、结果和验收矩阵中分别标注。

## 产品模块
1. 工作台：真实项目、素材、任务统计；最近创作；新建项目；常用工具；运行能力状态。
2. 创作工作室：17项工具按视频、图像、数字人、音频、后期、洞察分类；专用字段与校验；选素材/预览；保存草稿；真实提交；结果复用。
3. 视频工作室：文/图/多参考、首尾帧、提示词优化、输出比例/分辨率/时长/格式/音频、1–4条批量；历史网格/列表，复制提示词、复用配置、真实下载。
4. 创意 Agent：独立会话、标题修改、可恢复删除、消息持久化；LLM生成创意方案；交接脚本到视频工作室；模型未配置时明确阻止外部执行。
5. 创意工作流：游戏概念图→视频，前一步产物选择后才能继续；产品链接→产品资料→脚本→素材混剪/外部数字人合成。
6. 灵感雷达：用户导入/创建的参考广告；搜索、国家/行业/目标/比例过滤、指标排序、收藏、详情、可选逐秒指标；缺失数据标未知；无原站专有素材数据。
7. 视频拆解：自有视频或雷达引用；技术分镜检测本地可运行；语义分镜/机制诊断/反推提示词需视觉LLM；按版本保存，分区状态和结果；时间码跳转，提示词可编辑并交接。
8. 爆款复刻：选择参考、至多5产品图、名称/卖点/人群/场景/优化方向、语言/地区/字幕/输出配置；保存完整输入快照；真实外部任务。
9. 素材库：上传/预览/重命名/标签/搜索/类型筛选/回收站/恢复/下载；视频、图像、音频、字幕；来源与授权备注。
10. 项目：名称、描述、目标市场、品牌、素材和任务关联；草稿持久化；归档/恢复。
11. 任务与历史：搜索、状态/类型过滤；排队、处理中、成功、失败、取消；进度基于真实处理；事件日志；失败重试、取消、批量下载产物。
12. 设置：账号资料、服务商配置、模型ID与真实能力状态、授权角色/音色目录、调用使用记录、运行信息。

### 工具约束补充

- 图片输入（图生视频/AI生图/自定义/商品数字人）：PNG/JPEG，每图≤5MB；工具限定的数量与模型更严格上限取交集。GIF、SVG和改扩展名的非图片不能自动视作合法。
- 数字人音频为MP3/WAV；自定义与商品数字人≤60s，音频数字人≤5MB。原站没有明确的额外上限由本产品配置并显示，不能静默采用无限值。
- 生图比例为1:1、16:9、4:3、2:3、3:2、3:4、9:16；视频工具最终可选集合由真实模型能力决定。参考站展示名与供应商API模型ID分开保存，不能直接把展示名当API ID。
- TikTok数字人语速0.7–1.2（步进0.1）、音量10–100；普通数字人提供竖/方/横；字幕预设需有实际样式参数、可视预览和可验证渲染，不只保存名称。
- 混剪只接收MP4/MOV/QuickTime。产品名称≤500、描述≤500、卖点≤1000；最多10个卖点且每点≤10词。目标语言8种为英语、法语、德语、印尼语、西班牙语、马来语、泰语、越南语。推荐时长为本产品明确规则：默认30s并在提交前显示最终值。原站没有已验证的自动推荐算法。
- 混剪输出数量是本产品新增控制，最多100；每个输出独立子任务，父批次展示成功/失败/取消数量。字幕开启而无字幕文本时阻止提交；中文不会因选择英语而在本地自动变成英语。
- 链接生视频含可编辑产品资料、模板、口播语言、文案风格、角色、字幕、15/30/45/60s和竖/方/横。仅当模板及其所有阶段能力已实现时才允许提交完整视频，不能把生成脚本作为视频任务成功。
- AI配音图片提取Prompt、一键优化、音色克隆、口型同步、语义拆解均为独立能力；缺少相应能力时保留入口和解释，不用固定文本替代。
- 脚本生成需商品名、卖点≤2000、十进制数字价格、币种（本产品新增明确字段）、语言、TikTok/通用风格模型、7种脚本风格：行业秘密、打破常识、痛点提问、故事叙述、直接卖货、传达益处、科普教育。价格输入不混入币种字符。
- 目录宣称免费不作为独立产品承诺：原站脚本工具已观察到“免费”文案与积分不足反馈矛盾。本应用以当前供应商能力和实际使用记录为准。
- 未核验的上传大小/时长设安全可见上限（DEC）：一般视频100MB/120s、一般音频20MB/300s；工具或供应商有更严限制时取交集。批量素材采用每视频100MB/120s、单批合计1GB，超限须在上传与提交时说明。

### 服务商可执行合同

每个适配器必须声明可用能力、真实模型ID、允许格式/数量/时长、同步或异步协议、鉴权方式、状态映射及产物类型。实现清单记录所依据的供应商官方协议、测试fixture与支持能力；只有验证过的协议组合可显示“已配置可执行”。任意URL+密钥并不能自动实现17项工具。

外部调用分级显示：未配置、已配置未验证、连接验证通过、契约验证通过、真实推理验证通过。只检查密钥存在不得升级为“真实推理验证通过”。自动化测试使用受控协议fixture；不在测试中消耗用户付费额度。

数字人、商品交互、克隆、无痕修复、跨语言口型等没有直接实现的专用协议时，明确标为“需要支持该能力的服务商”，记录未完成项。可实现通用异步媒体网关协议，但应交付确切的请求/回调或轮询schema，且标注需要用户提供兼容网关；不得声称它直接兼容所有上游品牌。

## 核心业务约束
- 每个请求、素材、项目、任务、下载均归属当前用户。客户端隐藏不是授权。
- 输入在前后端共享schema，服务端再次验证媒体实际格式/大小/时长和关联素材所有权。
- 保存草稿不调用AI；提交前返回准确的能力可用性。未配置返回 PROVIDER_NOT_CONFIGURED，保留用户输入，不创建假成功。
- 幂等键+用户唯一；同键同输入返回同批次，同键不同输入返回冲突。
- 队列数据库原子领取，租约心跳；重启回收过期本地任务；外部provider已提交任务先查询，不盲目二次付费提交。
- 外部提交网络中断且无法判断服务商是否接受时进入“待核对”，记录幂等键和已知任务ID。只在服务商支持幂等或确认未受理时自动重试；未知结果不得再次自动付费提交。
- 父批次状态由子任务聚合；部分成功保留全部成功产物并可单独重试失败项。取消不能删除已完成子任务产物。
- 本地任务确认终止后取消为终态，旧worker不得覆盖。外部任务仅在provider确认cancelled时终结；accepted只表示已请求取消。外部running不支持取消时保留真实状态继续查询，不把停止本地轮询称为远程取消，也不执行具有删除记录语义的远程DELETE。界面说明远程可能仍产生费用；具体规则以`docs/adr/provider-contracts-research.md`为准。
- 原站商业积分不复制成支付系统。这里记录实际调用与任务统计，不伪造充值、支付、额度和价格；付费接入由独立服务商账户结算。
- 删除使用回收站或归档，保留已有任务输入；清理/永久删除另行确认。
- 本地导入广告指标由用户提供并注明来源，不编造投放数据或增长承诺。
- 远程URL抓取仅公开HTTP(S)，防内网/重定向/超限；不执行抓取HTML脚本。
- 所有产物先临时写入，验证后原子落盘；成功任务必须绑定真实产物或通过schema校验的结构化文本。

## 数据模型
users/sessions；projects；assets（元数据、sha256、storageKey、owner、deletedAt）；drafts；jobs（输入快照、父批次ID、状态、进度、lease、attempt、providerTaskId、提交核对状态）；job_events；job_outputs；providers（配置、加密密钥、能力声明及验证等级）；conversations/messages；radar_assets/favorites；analyses/analysis_versions；usage_events。

SQLite迁移有版本，WAL+foreign_keys+busy_timeout；数据库驱动实际版本包含WAL修复；媒体单独文件存储。

## 验收编号
A01 首次初始化/登录/登出/会话过期；密码哈希、受限登录、跨用户隔离。
A02 上传真实图音视频、拒绝伪装文件和超限；重命名/回收/恢复/下载；刷新保留。
A03 项目创建/编辑/归档、草稿重开、真实关联任务；状态跨重启持久。
A04 17工具字段校验与提交能力；未配置保留输入并明确错误。
A05 真实混剪至少6段输入，输出符合时长/尺寸/音轨，数量边界/取消/失败/恢复。
A06 幂等提交、并发领取、租约过期、取消竞争、重试不覆盖旧结果。
A07 provider契约测试（HTTP请求/响应/错误/二进制）；真实付费推理另记需要密钥的验收，契约测试不能冒充真推理。
A08 雷达导入搜索/组合筛选/收藏持久化/详情/交接；数据缺失显示未知。
A09 拆解结构与版本、失败状态、时间轴跳转、编辑提示词交接。
A10 视频工作室设置、批次、参考角色、结果复用与下载。
A11 响应式与键盘、加载/空/错误、可访问名称、无敏感信息泄露。
A12 Mac双击启动/重复启动/依赖缺失说明/停止/日志/SQLite和素材备份恢复。
A13 Agent创建/重命名/回收恢复/消息持久化；真实或受控fixture方案可交接视频草稿；无模型时保存输入并拒绝执行。
A14 游戏图→视频：无图禁止第二步，使用第一步真实产物并保存来源；链接工作流逐阶段可编辑/重试，抓取失败有手工录入，HTML脚本不执行。
A15 数字人/音色：切换模型后重校验文件格式与能力、过期角色ID拒绝、语速音量边界、字幕真实预览、克隆授权记录；无专用provider时不能错误显示成功。
A16 字幕：识别得到带时码原语SRT，翻译只在支持能力下执行；编辑保存后重新烧录，检查中文字幕字形、时间轴、音画同步与下载文件；遮挡/裁切不标无痕修复。
A17 混剪批次：6个真实不同片段生成至少2条可解码输出；每条时长容差≤1帧、尺寸符合配置、声轨策略正确；重复种子可复现，取消和部分失败不丢成功产物。数量0/101和5/101个输入均在服务端拒绝。
A18 外部提交歧义、轮询过期、无效/超大产物URL、重启后恢复轮询、认证错误、限流、取消后迟到完成。每种输出成功前验证实际MIME/可解码或结构化schema。

每个A编号必须在最终验收矩阵写明前置条件、操作、可观察预期、实际结果、证据文件和执行日期。缺密钥或额度的用例记“待真实推理验收”，不能用其余测试通过代替。
