## 交付路径
1. 范围：角色、功能模块、完整用户任务、外部依赖清单。
2. 行为调查：流程、表单字段、限制、状态、反馈，证据标记为 OBS（观察）、INF（推断）、DEC（设计决定）、BLOCK（未验证）。
3. 功能规格：数据关系、权限、规则、错误行为与可执行验收标准。
4. 重构设计：信息架构、交互原型、视觉规范、响应式与无障碍要求。
5. 实现：纵向业务流程、数据库、后台任务、文件处理、可配置 AI 适配器。
6. 验收：测试与人工浏览器核验、修复及实际能力矩阵。

## 事实边界
公开介绍展示的功能不等于该账号可用功能，不等于真实效果已经验证。
浏览器只能展示账号有权访问的行为，不能取得后台源码或隐藏算法。
AI 服务是否可真正运行，以独立配置的服务商凭证和实测结果为准。
不复用原站私有令牌，不依赖原站内部 API 为新产品提供后端。
