# 登录后调查：爆款雷达、视频拆解、历史、账户与积分

调查日期：2026-10-13（America/Los_Angeles）；网站部分记录显示北京时间 2026-10-14。调查方式：独立浏览器标签页的可见 UI/无障碍树，不读取后台接口、鉴权状态或未公开数据。

标记：**OBS** 为实际观察或交互验证；**INF** 为开发设计推断；**BLOCK** 为尚无法确认的行为。

## 2. 视频拆解 `/viral-deconstruction`

### OBS-D01 输入

- 空态「选择拆解视频，从收藏夹选择，或上传本地视频」；无视频时「限时免费 开始拆解」禁用。
- 选择对话框含收藏夹、本地上传两页签。收藏夹支持标题/品牌/素材 ID 搜索、行业筛选、最近/最早收藏排序、条数、选中后「使用此视频」。当前收藏为空。
- 本地上传约束：MP4、MOV、AVI、WEBM，最大 50MB。
- 有输入时显示播放器、来源「素材看板」、素材标题，更换视频、移除视频。更换打开同一选择对话框。
- 说明将输出分镜时间轴（结构、镜头、台词、剪辑）、爆款机制诊断（有效策略、短板、优化）、反推提示词（可编辑并用于生成）。

### OBS-D02 真实免费任务的状态与结果

经主代理授权，使用雷达公开示例素材执行一次 UI 明示「限时免费」的拆解。未购买、未上传用户文件、未提交收费生成。任务编号已省略，版本 V1，素材 ID 如上。余额前后仍为 0。

- 提交后按钮禁用并显示「正在创建拆解」。
- 创建完成后三个区块各显示「拆解中」，分区文案为正在识别结构/镜头边界、正在诊断有效策略/关键短板、正在生成结构化提示词。
- 全部重新拆解在处理中禁用。
- 本次最终三个区块均「已完成」。离开页面不丢任务，重新进入通过拆解记录恢复结果。
- 分镜时间轴：视频概述、阶段条（本条 2 阶段）、阶段起止时间、阶段目的/内容、可折叠阶段明细、每阶段多个镜头。镜头字段有时间、画面、景别和视角、动作、屏幕文字及中文释义。
- 点击时间轴阶段或阶段明细会播放对应时间片段，并出现「正在播放 0:02 - 0:05」。
- 机制诊断：核心优势、关键短板、优先动作；多个关键机制卡片，每项有名称、概要、吸引/留存/转化/互动标签、镜头证据时间段及描述、原理/问题/行动/收益四部分。
- 诊断页面声明 AI 分析只供创意参考，实际效果还受投放、账号、受众和发布时间影响。
- 反推提示词：可编辑多行「完整提示词」，本次结构包括生成目标、全片锚点、逐镜头时间轴、跨镜头连续性、关键约束。每镜头含画面构图、动作镜头衔接、声音文字。

- 每个分区有单独重新拆解，顶部有全部重新拆解，底部有去复刻。
- 版本下拉显示 `V1 - 首次拆解 · 最新`。

### OBS-A02 积分

## 5. 自我审查与实现验收建议

### 证据充分性

- 雷达正常检索/空态/重置、详情、拆解交接、拆解完整成功链路、任务跨导航持久化、历史查看、账户编辑字段、积分流水均有实际 UI 证据。
- 免费拆解仅执行一次；新增一条拆解记录和三条历史任务是本调查唯一有持久效果的操作。
- 无真实收费生成、无重拆/失败/部分成功验证、无订单购买测试、无收藏写入验证、无后台数据源/API证据；这些不是已验收能力。
- 浏览器 AX 关闭弹窗有短暂残留，已经以随后的 UI 或截图确认；不将短暂残留误记成功能。

### INF 推荐业务模型

- `RadarAsset`：品牌、标题、来源 ID/URL、行业层级、国家列表、目标列表、宽高、时长、点赞/评论/分享、CTR 百分位、预算档、逐秒表现序列。
- `Favorite`：用户 + 素材唯一键，收藏时间。
- `AnalysisTask`：用户、来源素材或上传资产、版本链、整体状态；三个独立 `AnalysisSection` 状态、错误及结果。父状态由子状态导出，避免全部成功与部分失败不一致。
- 分析输出用有 schema 的 JSON 保存，提示词单独保存可编辑文本；时间轴采用毫秒数据，展示时不能把不足一秒的镜头舍入成 `0:04 - 0:04`（参考站实际有此现象）。
- `CreditLedger`：不可变流水；余额/批次有效期、预扣/结算/退款应数据库事务化。参考站的积分数值和自有产品计费分开。
- `GenerationJob`/`Asset`：统一历史列表，并映射视频、图像、音频、分析结果的详情与下载能力。

### 建议验收用例

1. 关键词+多国家+行业子分类+版式组合筛选，结果和总数相符，重置恢复，空态可恢复；升降序稳定。
2. 收藏与取消收藏立即反馈且刷新持久；不可重复收藏；失败回滚；收藏用于拆解选择器。
3. 缺失指标显示未知而非 0；归一化曲线明确标注；详情关闭不丢列表筛选/滚动位置。
4. 上传 MIME/扩展名/体积双重校验；空输入禁用；选中素材从雷达到拆解和复刻传递同一资产。
5. 拆解三个任务异步执行；处理中禁止重复提交；离开再回来可恢复；部分失败能独立重试；版本不可覆盖。
6. 时间轴与播放器跳转一致，毫秒精度不产生零长镜头；文本可复制编辑，去生成预填最新版本。
7. 历史分页无重复/漏行，查看显示正确类型；文件下载有鉴权且说明水印；不得用演示视频冒充新生成结果。
8. 积分事务防重复扣除/负数，失败退款，过期清零有流水；无 API 配置时诚实提示，不能伪造成功。
9. 资料更新校验/取消无副作用，密码只由用户操作，任务和文件严格按用户隔离。
10. 本地 SQLite 产品没有参考平台 32 万素材数据库的授权副本，应支持自有导入/连接数据源，并明确演示数据。
