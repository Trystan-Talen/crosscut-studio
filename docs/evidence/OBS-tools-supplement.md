# 工具调查补充

## T01/T02 旧版图文生视频
- /tool?key=kl_i2v&id=32，/tool?key=kl_t2v&id=31。
- 模型：Seedance2.0、2.0-lite、Kling2.5、2.6、Veo3.1、3.1-fast。
- 创意描述最多2500字符；一键优化空输入禁用；预设示例；负面内容入口。
- 六种比例；默认480p；Seedance2.0时长4–15秒。
- 图生：PNG/JPG/JPEG，首帧必需、尾帧可选，每文件5MB。
- 当前历史为空；生成因积分不足未实测。

## T04 链接生视频
- /tool?key=p2v_flow&id=10。页面声明支持 TikTok Shop / Amazon / Shopify。
- 产品链接必填，最多1000字符；强调优势最多500字符；口播语言、风格、模板、数字人、字幕风格、时长、竖/方/横比例。
- 时长15/30/45/60秒。模板26项，覆盖气泡、全屏、抠像、产品卡片、上下/左右、Vlog、绿幕等不同布局。
- 文案风格46项，覆盖产品卖点、故事、行动号召、教程、痛点解决、生活方式、价格与优惠钩子等。
- 未执行产品抓取/付费合成，故不能据表单推断商品抓取成功率或模板最终实现。

## T15 电商广告视频脚本生成
- /tool?key=video_transcript&id=41。
- 商品名称及卖点必填，卖点2000字符；价格必须数字；目标语言；模型为TikTok风格或通用；脚本风格7项：行业秘密、打破常识、痛点提问、故事叙述、直接卖货、传达益处、科普教育。
- 验证：虚构商品“演示用旅行收纳袋”，输入价格19.90 USD触发“请输入数字”；改19.90提交后弹出积分不足。营销文案虽称不消耗积分，但实际流程当前被额度阻止。
- 曾弹出满意度调查；直接Escape退出，未提交评价、未领取积分、未购买。
- 不将此流程记为生成成功。
