## 用户任务
1. 发现参考广告 → 收藏/筛选 → 拆解 → 填写自有产品 → 复刻创作。
2. 上传素材或输入提示词 → 设置模型/输出 → 批量任务 → 预览/编辑/下载。
3. 商品链接或脚本 → 数字人/配音/字幕 → 广告视频。
4. 本地素材 → 混剪/转码/字幕等处理 → 可保存的真实产物。
5. 查找历史 → 复用配置 → 重试/取消 → 管理素材和产物。

## 优先级与外部边界
优先级只决定实现顺序，不缩减用户要求的全部可观察功能范围。
- P0：独立账号、素材、项目、SQLite 持久化、任务、真实本地媒体处理、结果下载、Mac 一键启动。
- P1：已观察全部 AI 工具的专用参数和真实服务适配；雷达数据导入/接入、拆解和复刻。
- P2：原站受限或尚未上线的能力不冒称已验证；受限项持续记录。
- 原站总积分为 0；爆款复刻另显示免费体验 35/35 积分。这是不同额度，不混为一谈。
- 未发现该账号的团队管理/管理员入口，不凭猜测复刻隐藏后台。
- AI 与广告投放效果数据需独立合法来源，不能以原站会话/私有接口作为产品后端。

本范围覆盖已观察入口，不意味着原站隐藏功能或模型效果已可完全验证。
